# 🛡️ DorkCraft AI Lab

An advanced, AI-powered OSINT reconnaissance, threat planning, and secure code auditing studio built with **Streamlit** and powered by ultra-fast **Groq LLM inference**.

## 🚀 Features
* **OSINT Dork Generator:** Generates precision Google search operators to locate exposed files and admin vectors.
* **Recon Strategy Planner:** Builds custom red-team workflows and tool chains for structured target assessments.
* **Code Security Auditor:** Identifies application security flaws and outputs hardened, refactored code blocks instantly.
